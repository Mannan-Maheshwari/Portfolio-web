# Mannan Maheshwari — Portfolio

A Resident Evil 4-inspired personal portfolio built with React, Vite, Tailwind CSS, and Three.js.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Portfolio content

- Update profile, skills, and achievements in `src/data/portfolio.js`.
- Edit project cards in `src/data/projects.js`.
- Add or replace the resume at `public/resume/Mannan_Maheshwari_Resume.pdf`.
- See [docs/EDITING.md](./docs/EDITING.md) for asset and content instructions.
